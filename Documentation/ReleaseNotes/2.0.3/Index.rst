======================
2.0.3  19 October 2026
======================

Patch release on the 2.0 line. AI Agent and MCP client fixes from the
feature branch, plus Content Blocks collection writes.

Here is the list of features and updates introduced in this release:

.. code-block:: none

   19-10-2026 [FEATURE] AI Agent: image texts for a named file in any readable folder; several matches or existing texts ask a question; language via isoCode; editor-written text is kept
   19-10-2026 [FEATURE] AI Agent: named pages are resolved from the current context (site languages and translations)
   19-10-2026 [FEATURE] MCP Tool site_languages_list: without a page, languages are grouped per site
   19-10-2026 [BUGFIX] AI Agent: reply after a failed last tool; one retry when a permission refusal was invented; voice-over write_table checks the written record
   19-10-2026 [BUGFIX] MCP Tool write_table: uid-keyed updates check every record before the first one is written
   19-10-2026 [BUGFIX] AI Agent: file-name lookups match only files inside the editor's file mounts
   19-10-2026 [FEATURE] MCP: session-less backend user so a write does not persist the user session
   19-10-2026 [BUGFIX] MCP Tool records_apply: refuse a translation copy onto a page that has no overlay in that language
   19-10-2026 [FEATURE] MCP Server: create a personal token from the module; the full token is shown once
   19-10-2026 [BUGFIX] MCP upload token errors explain how to use the token
   19-10-2026 [BUGFIX] MCP Tool records_apply: a new root page keeps the slug that was sent; a broken autogenerated site is removed
   19-10-2026 [FEATURE] MCP Server connect guides: ChatGPT, Gemini CLI, and Claude Code
   19-10-2026 [TASK] MCP Tool write_table: a dropped collection field names the child table and foreign_table_parent_uid
   19-10-2026 [BUGFIX] MCP Tool records_apply: a NEW parent on a collection child is resolved to that parent's uid; append keeps child order
   19-10-2026 [TASK] MCP initialize serverInfo.version reports 2.0.3
   19-10-2026 [RELEASE] Release patch version 2.0.3
