=============
Tab: Overview
=============

**Path:** :guilabel:`AI Foundation > AI Agent > Overview`

**What it shows:** the current state of the AI agent for your account.

*  **Counters** — :guilabel:`Registered tools`, :guilabel:`Executable now`,
   :guilabel:`Locked`, and :guilabel:`Contributing extensions`. A tool is
   *locked* when it has no declared severity or when its extension is not
   entitled to run.
*  **Keyboard shortcut** — choose how the AI agent opens in this browser.
*  **Availability** — whether the AI agent window is enabled for you, where
   the shortcut is stored (per browser), and that unsolicited suggestions
   are off by product policy.
*  **How tools register** and **Tools by owning extension** — every
   extension that registers tools, with total, executable, and locked
   counts.

**What you do here:**

#. Check that :guilabel:`Executable now` is greater than 0. If it is 0,
   see :ref:`ask-ai-agent-troubleshooting`.
#. Under :guilabel:`Keyboard shortcut`, select
   :guilabel:`Ctrl/Cmd+Shift+K (recommended)` or
   :guilabel:`Ctrl/Cmd+K (opt-in)`.
#. Reopen the AI agent, or reload other backend tabs, to apply the shortcut.

.. note::

   The shortcut is stored in the browser, not in the backend user record.
   Each editor sets it on each browser they use.
