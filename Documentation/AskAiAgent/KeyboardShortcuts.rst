==================
Keyboard shortcuts
==================

.. list-table::
   :header-rows: 1
   :widths: 30 70

   *  - Shortcut
      - Action
   *  - :kbd:`Ctrl/Cmd+Shift+K`
      - Open the AI agent. This is the default and recommended shortcut.
   *  - :kbd:`Ctrl/Cmd+K`
      - Open the AI agent (opt-in). Replaces the TYPO3 Live Search shortcut.
   *  - :kbd:`Enter`
      - Send the message.
   *  - :kbd:`Esc`
      - Close the AI agent window.

To change the shortcut:

#. Open :guilabel:`AI Foundation > AI Agent > Overview`.
#. Go to the :guilabel:`Keyboard shortcut` card.
#. Select :guilabel:`Ctrl/Cmd+Shift+K (recommended)` or
   :guilabel:`Ctrl/Cmd+K (opt-in)`.
#. Reload other open backend tabs.

The setting is stored per browser.

.. warning::

   :kbd:`Ctrl/Cmd+K` is the shortcut of TYPO3 **Live Search**. If you select
   it for the AI agent, Live Search no longer opens with the keyboard; it
   remains available through the search icon in the top bar. Keep the default
   :kbd:`Ctrl/Cmd+Shift+K` unless your editors agree on the change.
