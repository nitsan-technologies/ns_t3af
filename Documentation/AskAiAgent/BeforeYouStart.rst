================
Before you start
================

Make sure that the following requirements are met:

#. **An AI provider with tool calling is configured.** Add it in
   :guilabel:`AI Foundation > AI Providers` and click
   :guilabel:`Test connection`. See :ref:`AI Providers <ai-providers>`.
#. **You have access to the AI agent.** Administrators always have access.
   Editors need :guilabel:`AI Agent access` in their backend user group (see
   :ref:`ask-ai-agent-where`).
#. **You have normal TYPO3 permissions** for the pages and records you want to
   work with.

.. note::

   This guide describes the tools that ship with AI Foundation. Extensions
   that build on AI Foundation can add further tools; they are documented in
   their own manuals.
