==========
User Guide
==========

Practical day-to-day guidance for people who use **AI Foundation** in the
TYPO3 backend.

Editors can also ask the built-in **AI agent** for help with the page they
are working on: select the page in the page tree, click
:guilabel:`Ask AI Agent` in the top bar (or press :kbd:`Ctrl/Cmd+Shift+K`),
describe the task in plain language, and approve the prepared change. See
:ref:`Ask AI agent <ask-ai-agent>`.
